🗣️ Advanced Text-to-Speech Converter

A powerful and user-friendly Text-to-Speech (TTS) web application built using Streamlit.
It converts typed text or uploaded text files into high-quality speech with customizable male/female voices, speed control, and downloadable MP3 output.

This project is useful for students, creators, accessibility tools, bloggers, and anyone who wants a quick way to convert text into audio.

⭐ Features

✔ Text Input + File Input (.txt support)

✔ Male & Female Voice Options

✔ Works Offline using pyttsx3

✔ Adjustable Speech Speed

✔ Instant Audio Playback

✔ Download as MP3

✔ Simple and Clean Streamlit UI

📦 Installation
1️⃣ Clone the repository
git clone https://github.com/your-username/text-to-speech-advanced.git
cd text-to-speech-advanced

2️⃣ Install the required packages
pip install -r requirements.txt

3️⃣ Run the application
streamlit run app.py

🚀 How to Use

Run the app in your browser.

Type text manually or upload a .txt file.

Choose Voice Gender (Male / Female).

Adjust Speech Speed.

Click "Convert to Speech".

Listen to the audio instantly.

Download the MP3 file if needed.
